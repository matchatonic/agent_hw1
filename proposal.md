# Изменение: мини-трекер учебных задач на неделю

## Цель

Создать автономный мини-трекер учебных задач на неделю, позволяющий
добавлять и удалять задачи, отмечать выполнение и видеть прогресс по часам.

## Границы

В задачу входят:
- Задачи с полями id, title, hours, done.
- Добавление, удаление и переключение done с изменением данных.
- Проверка названия и часов с ошибками рядом с полями.
- Фильтр «активные», меняющий только видимый список.
- Итоговые часы, выполненные часы и прогресс по всем задачам.
- Читаемый интерфейс на ширине 390 px без горизонтального скролла.
- Подписи полей и кнопок.

Приложение MUST работать без CDN, внешних библиотек и API-ключей.

## Варианты поставки

- A: один tracker-v2.html со встроенными CSS и JavaScript.
- B: index.html, styles.css, app.mjs, domain.mjs,
  tests/acceptance.test.mjs.

Это альтернативные форматы поставки одного функционального объёма.

## Стартовый пример

| title | hours | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Начальный итог: всего 8 ч, выполнено 2 ч, прогресс 25%.

## Необязательное улучшение

Сохранение задач в localStorage. При недоступном хранилище приложение
показывает понятное сообщение и продолжает работу в памяти.

## Ограничение текущего этапа

Текущий результат — только спецификация.
Реализация выполняется отдельным запросом.
