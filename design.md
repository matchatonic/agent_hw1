# Данные и расчёты

## Модель задачи

| Поле | Тип | Правило |
|---|---|---|
| id | строка | Уникальный идентификатор задачи |
| title | строка | Непустая после trim |
| hours | число | От 0,5 до 24 включительно, кратно 0,5 |
| done | логическое | Признак выполнения |

Новая задача получает done=false.

## Состояние

- Полный массив задач — источник данных для операций и расчётов.
- Выбранный фильтр определяет видимые задачи.
- Значения формы хранятся отдельно от задач до успешной проверки.
- Ошибки привязаны к соответствующим полям.

Начальное состояние без сохранённых данных — стартовый пример:
«Чтение» — 2 ч, выполнена; «Практика» — 4 ч, не выполнена;
«Повторение» — 2 ч, не выполнена.

## Проверка ввода

1. Выполнить trim названия и проверить непустоту.
2. Проверить непустоту часов до числового преобразования.
3. Проверить, что часы являются конечным числом.
4. Проверить диапазон от 0,5 до 24 включительно.
5. Проверить кратность 0,5: удвоенное значение должно быть целым.
6. При ошибках сохранить введённые значения, показать ошибки рядом
   с полями и не изменять массив задач.
7. При успешной проверке добавить задачу.

## Расчёты

Обозначения:
- totalHours — сумма hours всех задач.
- doneHours — сумма hours задач с done=true.
- progress — 0 при totalHours=0; иначе округлённое до ближайшего
  целого значение 100 × doneHours / totalHours.

Фильтр не участвует в расчётах.

Контрольные значения:

| Состояние | Всего, ч | Выполнено, ч | Прогресс |
|---|---:|---:|---:|
| Стартовый пример | 8 | 2 | 25% |
| Стартовый пример, фильтр «активные» | 8 | 2 | 25% |
| «Практика» отмечена готовой | 8 | 6 | 75% |
| Все задачи удалены | 0 | 0 | 0% |

## Обновление состояния

- Добавление помещает проверенную задачу в полный массив.
- Удаление исключает задачу по id.
- Переключение меняет done задачи по id.
- После изменения обновляются видимый список и сводные показатели.
- Фильтр «активные» показывает только задачи с done=false.

## Организация файлов

### Вариант A

tracker-v2.html содержит разметку, стили и всю логику.

### Вариант B

- index.html — разметка и подключение локальных файлов.
- styles.css — оформление, включая компоновку на ширине 390 px.
- app.mjs — форма, события, фильтр и обновление интерфейса.
- domain.mjs — проверка данных, операции с задачами и расчёты.
- tests/acceptance.test.mjs — проверки поведения средствами Node.js
  без внешних библиотек.

## Необязательное сохранение

При реализации localStorage:
- При доступных сохранённых данных использовать их.
- Сохранённый пустой массив считать корректным состоянием,
  не заменять его стартовым примером.
- Сохранять данные после добавления, удаления и переключения done.
- Ошибки хранилища обрабатывать с понятным сообщением пользователю;
  текущие задачи остаются доступны в памяти.

## Интерфейс

Компоновка должна помещаться в ширину 390 px.
Поля и кнопки имеют понятные подписи, ошибки располагаются рядом
с соответствующими полями.
